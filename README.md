# Dusk

A Roku screensaver with three calm scenes: photoreal plates with procedural animation layered on top.

| Scene | Plate | Animation | Frame rate on a 3810X stick |
|---|---|---|---|
| Fireflies | porch-facing cabin in a meadow, late dusk | ~90 fireflies with weak Kuramoto coupling, stars, window glow, parallax | 60 |
| Snow | pine forest, cabin, clear night | aurora behind the trees, three depths of snow fading into the ground at their own distance | 30 (capped) |
| Blossoms | lantern-lit canal in Kyoto | tumbling petals that land on the water with a ripple, float and fade; gusts; swaying branch | 60 |

The settings screen (Settings › Theme › Screensavers › Dusk) picks one scene or cycles through all of them.

## The art and its license

Every image in Dusk was made for this project. No photographs or third-party artwork are used.

- **Plates** (the three backgrounds) were generated locally on a Mac with [Z-Image-Turbo](https://huggingface.co/Tongyi-MAI/Z-Image-Turbo) (Apache 2.0), run through [mflux](https://github.com/filipstrand/mflux). The exact prompts are in `gen/prompts/`, and the kept generations, with their seeds in the file names, are in `gen/drafts/`.
- Each plate was then **color graded** (PhotoCraft), **split into depth layers** using a depth map from [Depth Anything V2 Small](https://huggingface.co/depth-anything/Depth-Anything-V2-Small-hf) (Apache 2.0), and scaled and quantized for the Roku by the scripts in `tools/`.
- **Everything that moves** (fireflies, stars, aurora, snow, petals, ripples, window and lantern glows) is drawn procedurally by `tools/build_scene.py` and animated in BrightScript.

**License:** all images in this repository, generated and procedural, are dedicated to the public domain under [CC0 1.0](LICENSE-ART). You may use them for anything without asking or giving credit. The code is licensed under [Apache 2.0](LICENSE). `CREDITS.md` lists every shipped image with its source, prompt and seed.

## Layout

- `roku/dusk/`: the screensaver package (BrightScript, `roScreen`)
  - `source/main.brs`: entry points, scene loop, fades, frame cap
  - `source/plate.brs`: layered plate shared by all scenes (parallax drift, stars, window glows, foreground)
  - `source/{fireflies,snow,blossoms}.brs`: one file per scene
  - `source/settings.brs`: the settings screen
  - `scenes/*.json`: per-scene tuning and generated data (stars, windows, water spans)
  - `images/`: built assets (generated by the tools below; do not edit by hand)
- `gen/prompts/`, `gen/drafts/`: plate prompts and the generated plates that were kept
- `tools/`: the asset pipeline and device helpers
- `roku/bench*/`: throwaway performance benchmarks used to find the device's limits
- `CREDITS.md`: every shipped image and how it was made
- `STORE.md`, `store/`: Roku Channel Store listing text, artwork and checklist
- `PRIVACY.md`: privacy policy (linked from the store listing)
- `LICENSE` (Apache 2.0, code), `LICENSE-ART` (CC0 1.0, images)

## Asset pipeline

Run everything with the project venv (`.venv`, managed with `uv`). Plate generation needs the GPU, so run it outside the sandbox.

```sh
# 1. Generate a plate (Z-Image-Turbo via mflux; ~11 min per 1920x1088 image on a 24 GB M4 Pro)
W=1920 H=1088 tools/gen_drafts.sh fireflies 13

# 2. Grade (PhotoCraft): exposure EV, optional saturation
tools/grade.sh gen/drafts/zit_fireflies_s13.png gen/work/ff_s13_graded.png -0.3

# 3. Depth map and layer split (foreground = nearer than the ground at the same row)
.venv/bin/python tools/depth.py gen/drafts/zit_fireflies_s13.png gen/work/ff_s13_depth.png
.venv/bin/python tools/layers.py gen/work/ff_s13_graded.png gen/work/ff_s13_depth.png gen/work/ff_s13
#    snow:     --near 0.18 --band 0.02 --matte --land
#    blossoms: --matte --absolute --near 0.55 --region 760,0,1920,640   (branch only, s22)

# 4. Scene data: water outline (blossoms; trace it from the grid), lit windows/lanterns, stars
.venv/bin/python tools/water.py grid <plate> gen/work/grid.jpg
.venv/bin/python tools/water.py set <plate> roku/dusk/scenes/blossoms.json "x,y x,y ..."
.venv/bin/python tools/find_window.py <plate> roku/dusk/scenes/<scene>.json --max 3
.venv/bin/python tools/stars.py <depth> roku/dusk/scenes/<scene>.json --count 35

# 5. Pack into roku/dusk/images (scales layers for parallax, quantizes PNGs, draws sprites)
.venv/bin/python tools/build_scene.py fireflies gen/work/ff_s13_bg.jpg gen/work/ff_s13_fg.png
.venv/bin/python tools/icons.py gen/work/ff_s13_graded.png
```

## Device workflow

The dev Roku's address and password live in `.env` (gitignored): `ROKU_IP`, `ROKU_DEV_PASSWORD`.

```sh
tools/sideload.sh roku/dusk                       # dev build (runs as an app; fails loudly on errors)
tools/sideload.sh roku/dusk --release             # screensaver-only build, as shipped
curl -X POST "http://$ROKU_IP:8060/launch/dev?scene=snow"     # or scene=cycle&cycle=20, or settings=1
.venv/bin/python tools/console.py 20              # BrightScript console (FPS is printed every 10 s)
tools/screenshot.sh build/shot.jpg                # grab the current frame
tools/package.sh                                  # signed store package -> build/dusk-<version>.pkg
```

To test the real screensaver and its settings, install the `--release` build and choose Dusk under Settings › Theme › Screensavers. The dev build includes `Main()` and a `title`, which makes Roku hang on the splash when opening "Change screensaver settings".

## Things learned about the target (Roku Streaming Stick+ 3810X)

- Draw calls are cheap on the GPU side, but each costs ~15–20 µs of BrightScript time; script and GPU time add up per frame.
- About six full-screen alpha layers fit in a frame in isolation; real scenes with script work fit about four. Heavy scenes cap at 30 fps via `"fps"` in their JSON.
- Drawing *into* an `roRegion` of an offscreen `roBitmap` does not render; regions as draw *sources* work.
- `Run` is a BrightScript built-in, and identifiers are case-insensitive, so a local variable can shadow a global function.
- Sideload space is small; quantized palette PNGs keep the package around 3 MB.
- "Change screensaver settings" only works for a screensaver-only package (no `title`, no `Main()`; explicit `run_screensaver*` entries). The settings context also needs SceneGraph, not `roScreen`.
- ECP keypresses return 403 unless "Control by mobile apps" is set to permissive.
